Number-Word-Game 🎮🔢

A simple and fun Number Word Game where players convert numbers into their corresponding words.

📌 About the Game

The Number-Word-Game helps users practice writing numbers in words. A number is displayed, and the player needs to enter the correct word representation.

Example
Number: 47
Answer: Forty-Seven

✨ Features
🔢 Displays random numbers.
✍️ Allows players to enter the number in words.
✅ Checks whether the answer is correct.
🎯 Keeps track of the player's score.
🔄 Allows the player to play multiple rounds.
🎉 Simple and beginner-friendly gameplay.
🕹️ How to Play
Start the game.
A number will appear on the screen.
Type the number in words.
Submit your answer.
The game tells you whether your answer is correct.
Continue playing and improve your score.
